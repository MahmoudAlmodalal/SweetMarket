## المرحلة 0: البنية التحتية واللبنات التأسيسية (Foundation & UI Primitives)

### TASK-001: إعداد مشروع Next.js وضبط الخطوط وTailwind والهوية
- **النطاق:** تهيئة Next.js 14/15 App Router مع TypeScript، وتضمين خطوط `El Messiri` و `IBM Plex Sans Arabic`، وتفعيل ألوان `candy` و `DESIGN.md` ونصف القطر `candy-card` داخل `tailwind.config.js`.
- **المدخلات:** `design-system/tailwind.config.js`، `DESIGN.md`.
- **المخرجات المتوقعة:** ملف `src/app/layout.tsx` مضبوط باتجاه `dir="rtl"` ولغة `lang="ar"` مع تطبيق لوحة ألوان كاندي لوز.
- **التبعيات:** لا يوجد.
- **معايير القبول:** ظهور صفحة فارغة باللون الوردي/الكريمي الفاتح مع الخط العربي الصحيح وبدون أخطاء تجميع.
- **طريقة التحقق:** `npm run build` أو `npm run dev`.

### TASK-002: بناء مستودعات البيانات الوهمية (Mock Data Stores)
- **النطاق:** كتابة ملفات البيانات الوهمية للمنتجات، التصنيفات، مناطق التوصيل، الطلبات الأولية، وحسابات الإدارة.
- **المدخلات:** `docs/FRONTEND_DATA_CONTRACTS.md`.
- **المخرجات المتوقعة:** `src/data/mock/products.ts`, `categories.ts`, `zones.ts`, `orders.ts`, `users.ts`.
- **التبعيات:** TASK-001.
- **معايير القبول:** توفر بيانات مطابقة لتصاميم Stitch (بقلاوة، كيك، هدايا) مع أسعار واقعية بالشيكل وعمليات جلب غير متزامنة (Async simulated delay).
- **طريقة التحقق:** فحص الاستيراد واكتمال الأنواع عبر `npx tsc --noEmit`.

### TASK-003: بناء مكونات الواجهة الأولية (UI Primitives)
- **النطاق:** بناء عناصر: Button, Input, Badge, Dialog, Drawer, Card, Skeleton, Toaster.

- **المخرجات المتوقعة:** مجلد `src/components/ui/` مكتمل بجميع عناصره.
