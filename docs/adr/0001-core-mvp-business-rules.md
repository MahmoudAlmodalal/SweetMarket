# 0001 - اعتماد الشراء كزائر والدفع عند الاستلام وحصر الإلغاء بالمدير في MVP

## السياق والقرار (Context & Decision)
في إصدار MVP لمتجر حلويات كاندي لوز (Candy Loz):
1. **الطلب كزائر (Guest Checkout):** تم اعتماد الشراء كزائر دون إلزام الزبون بإنشاء حساب أو تسجيل دخول، لحذف أي احتكاك ورفع نسبة إتمام الطلبات.
2. **طريقة الدفع (Payment Method):** تم اعتماد الدفع نقداً عند الاستلام (Cash on Delivery - COD) فقط، وتأجيل بوابات الدفع الإلكتروني والتحويل البنكي للمراحل القادمة.
3. **نموذج التوصيل (Delivery Model):** يتم التوصيل بسائقين تابعين للمتجر وفق مناطق توصيل جغرافية محددة مسبقاً برسوم ثابتة لكل منطقة، مع تعطيل خيار "الاستلام من الفرع" في MVP.
4. **أدوار لوحة الإدارة (Admin RBAC):** وجود دورين داخل لوحة التحكم: «موظف» (Staff) لمتابعة وتجهيز الطلبات وتحديث توفر المنتجات، و«مدير» (Manager) للإدارة الكاملة والإلغاء؛ ويبقى السائقون خارج النظام التقني.
5. **سياسة الإلغاء (Cancellation Policy):** لا يملك الزبون زر إلغاء مباشر بعد إرسال الطلب، والإلغاء محصور بالمدير فقط مع اشتراط كتابة سبب الإلغاء في سجل التدقيق.

## العواقب والبدائل المرفوضة (Consequences & Considered Options)
- تم رفض إلزام المستخدم بالتسجيل لتقليل كلفة بناء واجهات الحسابات وإدارة الجلسات المعقدة للزبائن في MVP.
- تم رفض بوابات الدفع الإلكتروني حالياً لعدم وجود متطلبات ربط بنكي معقدة في مرحلة الإطلاق الأولى.
- تم استبعاد واجهة مخصصة للسائق؛ يتم إرسال بيانات العناوين والأرقام للسائقين عبر الطباعة أو واتساب.
