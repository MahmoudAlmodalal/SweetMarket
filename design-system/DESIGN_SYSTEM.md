# نظام تصميم كاندي لوز (Candy Loz Design System)
## الإصدار: 1.0.0 — بنية "Crème" للحلويات الفاخرة (Confectionery Aesthetic)
**المرجع الحي المستخرج عبر Playwright:** [candyloz.com/ar](https://candyloz.com/ar)

---

## 1. نظرة عامة وفلسفة التصميم (Design Philosophy)

تم استخراج وهندسة هذا النظام التصميمي بدقة متناهية عبر أداة **Playwright** مباشرة من المتجر الإلكتروني الحي **كاندي لوز (Candy Loz)**.
يعتمد النظام ثيم **"Crème" v6** (Ice-Cream Parlour & Boutique Confectionery Style)، والذي يتميز بـ:
1. **ألوان ناعمة ومبهجة:** تدرجات التوت البري الفاخر (`#A02857`) والفراولة الحيوية (`#D72D58`)، مع خلفية قماشية كريمية دافئة بلون المارشملو (`#FFFAF8`).
2. **ألوان الكروت الدوّارة (Rotating Pastels):** ميزة بصرية فريدة تمنح كل بطاقة منتج لون خلفية باستيلي مختلف (حليب الفراولة، الفستق، الورد، الفانيلا، الخوخ، وغزل البنات الأزرق).
3. **خط عربي ثنائي متناغم:**
   - **El Messiri:** للعناوين البارزة، أسماء المنتجات، والشعارات؛ يمنح انطباعاً احتفالياً عريقاً.
   - **IBM Plex Sans Arabic:** للنصوص، الأسعار، الأزرار، والواجهات؛ لأعلى مقروئية ووضوح هندسي على الشاشات والجوالات.
4. **حواف ناعمة ومنحنيات مستديرة:** زوايا كروت بمقدار `22px`، أزرار وحقول بحث بتصميم الكبسولة الكاملة `99px` (Pill Radius)، وشريط تنقل سفلي عائم (Floating Dock) للجوال.
5. **ظلال ملونة (Tinged Shadows):** ظلال مشبعة بلمسة توت خفيفة (`rgba(184, 92, 110, 0.08)`) بدلاً من الظلال الرمادية الباهتة.

## 4. المسافات والزوايا والظلال (Geometry, Radius & Shadows)

### 4.1 زوايا الحواف (Corner Radius)
- **البطاقات (Cards):** `22px` (`--radius-card`)
- **حاويات الأقسام (Sections):** `32px` (`--radius-section`)
- **الكبسولات (Pills):** `99px` للأزرار، البادجات، شريط البحث، وتبويبات المنتجات.
- **الأيقونات الدائرية:** `50%` لأزرار الإجراءات السريعة والمفضلة وحساب المستخدم.

### 4.2 الظلال (Elevation)
- **`--shadow-1` (منخفض):** `0 4px 14px rgba(184, 92, 110, 0.08)` — للبطاقات الافتراضية، والأزرار المفرغة.
- **`--shadow-2` (متوسط - للتحويم):** `0 14px 34px rgba(184, 92, 110, 0.14)` — عند تحويم الفأرة فوق كرت المنتج.
- **`--shadow-3` (مرتفع):** `0 26px 60px rgba(124, 29, 67, 0.18)` — لقوائم السحب والقوائم الجانبية المودال.
- **`--shadow-cta` (توهج زر الشراء):** `0 12px 26px rgba(215, 45, 88, 0.30)` — لزر "أضف إلى السلة" الفراولي.

## 5. مواصفات المكونات الرئيسية (Component Specifications)

### 5.1 كرت المنتج (Candy Product Card)
- **الخلفية:** تتناوب بين `--cl-pastel-1` إلى `--cl-pastel-6`.
- **صندوق الصورة:** نسبة أبعاد `4:5`، زوايا مستديرة `18px`، خلفية نصف شفافة `rgba(255, 255, 255, 0.45)`.
- **زر المفضلة:** دائري `34px` في الزاوية العلوية، خلفية بيضاء `rgba(255, 255, 255, 0.85)`، لون الأيقونة فراولة `#D72D58`.
- **سلوك التحويم (Hover State):**
  - ارتفاع الكرت بمقدار `translateY(-8px)`.
  - تكبير الصورة بمقدار `scale(1.08) translateY(-4px)`.
  - ظهور ظل ناعم `--shadow-2`.
- **زر الإضافة السريعة للسلة:** كبسولة بيضاء بارتفاع `40px`، نص توتي، وعند التحويم تتحول إلى اللون الفراولي بنص أبيض.

### 5.2 حقل البحث (Candy Search)
- **الارتفاع:** `50px`.
- **الاستدارة:** كبسولة كاملة `99px`.
- **الخلفية:** `--cl-soft` (`#FFF5F8`).
- **الحدود:** `1.5px solid #F4E1E6`، وعند التركيز (Focus) تصبح وردية مع هالة توهج `0 0 0 5px rgba(215, 45, 88, 0.08)`.
- **زر البحث:** دائري بداخله أيقونة عدسة بيضاء وخلفية فراولة.

### 5.3 أزرار التحكم والتبويبات المقسمة (Segmented Control Tabs)
- كبسولة خارجية بيضاء بحدود وردية وظل خفيف.
- التبويب النشط يحصل على خلفية تدرجية:
  `linear-gradient(135deg, #EF4F78 0%, #D72D58 45%, #A02857 100%)`
  مع نص أبيض وظل توتي بارز.

### 5.4 شريط التنقل السفلي للجوال (Floating Bottom Dock)
- شريط عائم فوق أسفل الشاشة بمقدار `12px`.
- خلفية بيضاء، زوايا `24px`، وظل عائم `--shadow-dock`.
- زر السلة الرئيسي بارز بلون الفراولة وبادج دائري بعداد العناصر باللون التوتي.

## 6. كيفية استخدام النظام في المشروع (How to Consume)

### الخيار 1: عبر ملف CSS المباشر
قم بتضمين الملف في رأس الصفحة:
```html
<link rel="stylesheet" href="./design-system/tokens.css">
```

### الخيار 2: عبر Tailwind CSS
تم تضمين إعدادات Tailwind في `design-system/tailwind.config.js`. يمكنك استخدام الكلاسات مباشرة:
```html
<button class="bg-candy-strawberry hover:bg-candy-berry text-white font-sans font-extrabold rounded-candy-pill shadow-candy-cta px-6 py-3">
  أضف إلى السلة
</button>
```

### الخيار 3: عبر ملف JSON (Design Tokens)
يمكن قراءة `design-system/tokens.json` في أي أداة بناء (Style Dictionary, Figma Tokens, React Native, iOS, Android).

## 7. الملفات المتوفرة في المجلد
1. `tokens.json`: قاموس الرموز الخام بنية الـ 3 طبقات (Primitive -> Semantic -> Component).
2. `tokens.css`: متغيرات CSS وكلاسات جاهزة للاستخدام الفوري.
3. `tailwind.config.js`: امتداد ثيم Tailwind بالكامل.
4. `showcase.html`: صفحة معاينة تفاعلية حية لجميع المكونات والألوان.
5. `DESIGN_SYSTEM.md`: هذا الدليل الشامل.
